# Stock AI 用户使用手册

> A 股多模型赛马模拟交易系统 · 仅供学习研究，不构成投资建议。  
> 模拟撮合遵守 T+1 / 整手 / 涨跌停 / 佣金印花税，与实盘仍有差异。

---

## 1. 系统是什么

Stock AI 是一个 **多账户赛马台**：

| 赛道 | 选手 | 节奏 |
|------|------|------|
| **AI 日频** | 各 LLM 模型 + 合议组合 | 默认交易日 **14:35** 全量决策 |
| **规则周频** | S2 因子前 N、池内等权、研究晋升臂 | 默认 **周一 14:50** 调仓 |

所有选手共用 **同一股池**、同一模拟撮合规则，资产曲线可同屏对比。

典型一天：

```
14:05  AI 选股（可选）→ 维护共享股池
14:35  AI 决策流水线 → 分析师辩论 → 交易员 → 风控 → 撮合
盘中   每 15 分钟监控 AI 持仓（浅线告警 / 深亏可强制砍）
周一   14:50 规则策略调仓
```

## 2. 快速上手（5 步）

### 2.1 启动

**Docker（推荐）**

```bash
# 准备 .env（至少填 LLM_API_KEY；扶摇 Key 用于因子/规则）
docker compose up -d
# 浏览器打开 http://localhost:8000
```

**本地开发**

```bash
# 后端
cd backend && source .venv/bin/activate
uvicorn app.main:app --port 8000

# 前端（另一终端）
cd frontend && npm run dev
# 默认 http://localhost:5173 ，代理到后端 8000
```

### 2.2 配置密钥（必做）

打开 **设置 → 密钥**：

| 项 | 用途 |
|----|------|
| LLM Base URL / API Key | 所有 AI 模型共用的 OpenAI 兼容接口 |
| 扶摇 API Key | 日 K、估值、财务、规则调仓 / 回测主数据源 |
| Tushare Token | 可选，默认主路径不用 |

侧栏底部显示「扶摇已连接 / 未配置」便于自检。

### 2.3 准备股池

进入 **股池**：

1. 手动输入 6 位代码添加（如 `600519`），或  
2. 点 **AI 选股**（约 1–2 分钟，需已启用 LLM）。

说明：

- 股池有上限（默认 **30**，可在 **设置 → 选股** 调整）。
- **手动**添加的票不会被自动淘汰；**AI** 入池的票连续未被看好且无任何账户持仓会被移除。
- 满池后无法再添加，需先移除或提高上限。

### 2.4 确认参赛账户

进入 **参赛账户**：

- 种子默认含若干 LLM、合议与规则账户。
- 可 **添加 LLM**（展示名 + API 模型名）、**新建合议**（≥2 个 LLM 成员，多数票合成，零额外调用）。
- 开关控制是否参与决策 / 调仓。
- **规则账户不可删除**；研究晋升臂请到 **研究** 页退役。

### 2.5 跑一轮

- 顶栏 **立即 AI 决策**：对股池 + 持仓中的股票跑完整流水线（耗时长、消耗 Token）。
- 顶栏 **规则调仓**：对启用的规则策略按当前股池立即再平衡（**会真实买卖模拟盘**，有确认框）。
- 运行中可 **查看过程 / 停止**（协作取消：当前 Agent 结束后停，已成交订单保留）。

### 2.6 界面如何引导你

- 顶栏下方 **待办条**：缺密钥 / 空股池 / 无 AI 账户 / **规则尚未调仓** 时会显示快捷跳转。
- **战报 / 策略**：规则仍空仓时提示「立即调仓」，否则规则赛道会一直停在 0%。
- **股池 · AI 选股**：会轮询到结束并自动刷新列表。
- **决策列表 / 详情**：展示买卖汇总、选股入池/移出、失败原因。

## 3. 各页面说明

### 3.1 战报（首页）

- **样本门槛**：账本平仓笔数 / 交易日门槛；未达标不授「可竞赛」冠。
- **双赛道排行**：AI（LLM + 合议）vs 规则；点选手查看该账户 **持仓明细**。
- **收益曲线**：各启用账户收益率 vs 沪深 300。
- **重置全部账户**：清空持仓、订单、决策、账本等，资金回到初始值（不可撤销，请谨慎）。

### 3.2 策略

- **对照排行**：规则臂夏普主序；样本不足灰显；达标后才可能授冠。
- **单独调仓 / 立即调仓**：只动规则侧，不影响 AI 账户。
- **S2 因子截面**：按需点「加载截面」（拉日 K 可能较慢，避免一进页就卡住）。

### 3.3 研究

闭环：**理论 → 规格 → 回测 → 晋升**。

1. 输入投资理论 → **创建并 AI 译规格**（无 LLM 时走启发式）。
2. 改因子 / TopN / 调仓 / 止损止盈 → **保存 / 确认规格**。
3. **回测**（依赖股池 ≥2 只 + 扶摇数据）。
4. 建议为晋升 / 废弃 / 复核；**晋升**会开独立规则账户参赛。
5. **规则库网格**：批量扫因子×TopN 等，勾选存活者导入为假说后再人工晋升。
6. **退役**：停用已晋升账户，不直接删库。

### 3.4 股池

- 列表展示代码、名称、来源（AI / 手动）、现价涨跌、选入理由。
- AI 选股与决策运行互斥（一方在跑时另一方会提示稍后）。

### 3.5 决策

- 列表：手动 / 定时 / AI 选股触发；摘要默认突出买卖，观望可折叠。
- **详情**：按模型 Tab 看大盘环境、各 Agent 报告、最终动作；运行中显示进度条。
- **调试开关**：展示 Agent 输入摘要。
- 状态含：运行中 / 完成 / 失败 / 已取消。

### 3.6 成交

- **交易记录**：买卖订单（成交 / 拒绝原因）；可按账户筛选。
- **盘中监控事件**：止盈/止损警戒、深亏强制砍等（仅 **AI 账户**；规则臂不走盘中监控）。

### 3.7 参赛账户

- LLM / 合议 / 规则列表与启停。
- 抽屉查看单账户持仓。
- 删除 LLM 前若被合议引用需先拆合议。

### 3.8 设置

| 分组 | 内容 |
|------|------|
| 密钥 | LLM / 扶摇 / Tushare |
| 数据源 | 扶摇/新浪/Tushare/RSS 启停、超时、失败策略、探测、RSS 源列表 |
| 通知 | Bark Server、Device Key、点击地址、通知类型与连通测试 |
| 账户 | 初始资金（新户/重置生效） |
| 撮合 | 佣金、印花税、过户费 |
| 选股 | 股池上限、筛选阈值、淘汰 miss 次数 |
| Prompt | 各 Agent 系统提示词 |
| 风控 | 单票/总仓位上限、浅线告警、深亏阈值 |
| 因子 | TopN 等 |
| 参赛账户 | 只读摘要，跳转管理页 |
| 调度 | 决策/选股/监控/规则调仓时间 |
| 赛马 | 样本门槛、可竞赛臂上限 |
| 日志 | 全局日志级别与保留天数 |
| 调试 | 流水线详细日志、默认展示 IO |

改带「改后重载调度」标签的项会自动重载定时任务。危险项会二次确认。

#### Bark 人工介入通知

1. 在 iPhone 的 Bark App 中复制测试 URL 里的 Device Key。
2. 打开「设置 → 通知」，填写 Bark Server（官方服务为 `https://api.day.app`）和 Device Key。
3. 可选填写手机能够访问的 Stock AI 地址，例如 `http://192.168.1.20:18000`，用于点击通知跳转。
4. 保存后先点「发送测试通知」，确认收到后再打开「启用 Bark 通知」。

系统只推送待审批候选计划、持仓风险复审、决策/选股失败或降级；普通观望不推送。Bark 失败只写日志，不会改变计划、资金或持仓。

## 4. 决策流水线（AI）

对 **每个启用 LLM**，对股池 ∪ 持仓中每只股票：

```
大盘环境分析师
    ↓
技术 / 基本面 / 新闻情绪 分析师
    ↓
多空辩论（2 轮）
    ↓
交易员（注入大盘 + 事实底稿 + 历史反思）
    ↓
风控经理 → 代码硬风控 → 模拟撮合
    ↓
本轮反思入库
```

然后 **合议组合** 按成员当日决策 **多数票** 合成（过半才动手，仓位取获胜方均值；无额外 LLM）。

**硬风控（不依赖 LLM）** 默认：

- 单票 ≤ 30% 总资产  
- 单次买入 ≤ 50% 可用资金  
- 总仓位 ≤ 90%  

可在 **设置 → 风控** 调整。

**Token 成本提示**：每票约 9 次 LLM 调用，另每模型每轮 1 次大盘 + 1 次反思。股池 30 只 × 3 模型 ≈ 大量调用，请注意账单。

## 5. 规则策略与研究

| 策略 | 逻辑 |
|------|------|
| 池内等权 | 股池内等权持有（锚） |
| S2 周频前 N | 短/中动量、低波、EP、BP、ROE 等截面 z 分合成，取前 N 等权 |
| 研究晋升 `res_*` | 你在研究页确认并晋升的规格，参与同一套周频调仓 |

样本门槛（默认）：**≥60 交易日** 且 **≥100 笔平仓**（账本 `trade_ledger`，AI 与规则成交均计入）后，才进入可竞赛授冠评估。

## 6. 盘中监控

- 扫描 **启用的 LLM / 合议** 持仓（**跳过规则账户**）。
- **浅止损 / 止盈线**（默认 -8% / +15%）：默认 **仅告警**，不自动卖。
- **深亏**（默认 -15%）：可 **强制砍仓**（不经 LLM），每日每股至多一次相关动作。
- 事件在 **成交** 页查看。

## 7. 调度与手动操作

| 任务 | 默认 | 说明 |
|------|------|------|
| AI 选股 | 交易日 14:05 | 可关；股池页可手动触发 |
| AI 决策 | 交易日 14:35 | 顶栏可手动 |
| 盘中监控 | 每 15 分钟 | 设置可调间隔 |
| 规则调仓 | 周一 14:50 | 顶栏/策略页可手动（确认后执行） |

非交易时段手动决策仍会按 **最近价** 撮合，便于调试。

**取消决策**：协作式——当前 Agent 结束后停止；**已成交订单不回滚**。

## 8. 常见问题

**Q: 点「立即 AI 决策」报错？**  
检查：股池非空、至少 1 个启用 LLM、已配置 LLM API Key、当前没有另一轮在跑。

**Q: 规则调仓失败？**  
检查扶摇 Key、股池非空、对应规则账户已启用。

**Q: 股池加不进去？**  
是否已满上限；代码是否 6 位 A 股（不含 ST/北交所）。

**Q: 决策很慢？**  
正常：每票多次 LLM + 事实底稿。可减股池、减启用模型，或用合议减少额外调用。

**Q: 为什么规则持仓不被盘中止损？**  
设计如此：规则靠周频再平衡与回测内事件；盘中监控只作用于 AI 赛道。

**Q: 合议为何「观望」？**  
成员对该票无过半一致买卖动作时，合议观望；若多数 hold 且目标仓位 >0，界面显示「继续持有」。

**Q: 重置账户后研究假说还在？**  
研究列表保留；已晋升账户资金会被重置。需要可再退役/废弃假说。

**Q: 数据源关了还看到旧行情？**  
部分接口有短 TTL 缓存（约数分钟）；设置改完后探测或稍等。

## 9. 数据与风险说明

- **主行情 / 基本面**：同花顺扶摇（需 Key）。  
- **新闻**：本地 RSS（零 Key，源列表见设置 → 数据源）。  
- **模拟盘**：理想化成交，涨跌停阈值近似，非券商实盘。  
- **本系统不构成投资建议**，请勿用于实盘自动交易决策的唯一依据。

## 10. 推荐日常流程

1. 早晨或盘前：看 **战报** 排行与持仓。  
2. 14:05 前后：确认股池 / 是否需要手动 AI 选股。  
3. 14:35：自动或手动 AI 决策，在 **决策详情** 跟进度。  
4. 盘中：看 **成交** 监控事件（告警不必慌，深亏强制砍会有记录）。  
5. 周一：确认规则调仓是否成功；在 **策略** 看夏普与样本。  
6. 有想法：去 **研究** 写理论 → 回测 → 谨慎晋升。  
7. 密钥与参数变更：只在 **设置** 改，改完看调度是否重载成功。
