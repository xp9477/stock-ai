## 已拍板

### 1. 设置 = 运行控制台

| # | 决策 | 选择 |
|---|------|------|
| 1.1 | 设置定位 | **运行控制台**：凡改变系统行为的杠杆都进设置（不只密钥） |
| 1.2 | 数据源栈 | **固定角色 + 可配启停/超时/失败策略 + 健康状态**；不可拖拽重排优先级 |
| 1.3 | 数据源角色（写死） | 扶摇=主行情/财务；新浪=选股截面兜底 + 指数/日历（无 Key·AKShare）；腾讯=实时；Tushare=备；RSS=新闻 |
| 1.4 | 收口范围 | **运行时全收口**：行为杠杆进 `settings_registry`；`.env` 仅冷启动 bootstrap |
| 1.5 | 危险等级 | **三级**：随时改 / 改前强确认 / 冻结或仅新赛季生效（初始资金、费率等） |

**实现提示（未开工）**

- 新增设置分组如「数据源」：新浪等无 Key 源也要展示  
- 扫描 `.env` / 代码常量 → 迁入 registry  
- UI：override / .env / default 来源标注；冻结项与强确认交互  

### 2. AI 决策过程与日志

| # | 决策 | 选择 |
|---|------|------|
| 2.1 | 运行中主视图 | **实时流水线**：按 Agent 时间线（排队/进行中/完成/失败），完成可看摘要/全文 |
| 2.2 | 调试层 | **同页「调试」开关**：raw prompt/completion、token、耗时、重试、HTTP；默认关；密钥永不入日志 |
| 2.3 | 全局日志 | **有**独立全局日志入口；与单次 run 流水线并存 |
| 2.4 | 日志保留 | 方案 A 向：可清理/环形思路；**默认 30 天，保留天数可设置** |
| 2.5 | 中途停止 | **协作式取消**：当前 Agent 结束后不再开新工作；已落库保留；run=`cancelled`；撮合前检查避免半票乱单 |
| 2.6 | 关联 | 日志尽量带 `run_id`，流水线 ↔ 全局日志可跳转 |

**实现提示（未开工）**

- 复用/加强 `AgentOutput` 边产边出 + 轮询或 SSE  
- `POST` 取消端点 + engine 协作点  
- `log_retention_days` 进 settings（默认 30）  

### 3. 策略页 vs 研究页

| # | 决策 | 选择 |
|---|------|------|
| 3.1 | 信息架构 | **拆两个导航入口**：「策略」= 仅在跑的；「研究/回测」= 理论与验证 |
| 3.2 | 「策略」页优化重点 | **D = A+C**：赛马对照（收益/回撤/夏普/样本门槛/最近调仓）+ 类型与生命周期标签（内置规则 / 研究晋升等） |
| 3.3 | 非本轮主目标 | 纯按钮打磨（B）随手做，不单独立项 |

**实现提示（未开工）**

- 路由：如 `/strategies` + `/research`（名可再定）  
- 策略页：对照指标、来源标签、启停；基线回测入口可保留或链到研究页  

### 4. 理论回测闭环

| # | 决策 | 选择 |
|---|------|------|
| 4.1 | 理论输入 | **D：自然语言进料 → AI 译成结构化规格草稿 → 人确认后才回测**；可复现真源=结构化规格 |
| 4.2 | 回测引擎 v1 | **B：周频截面策略 + 简单日线事件规则**（如均线突破买入、止损卖出）；非日内/网格/在线 ML |
| 4.3 | 通过/废弃判定 | **B：硬门槛建议标签 + 人最终确认**；禁止过拟合一条曲线自动上臂 |
| 4.4 | 晋升后形态 | **A：新开独立模拟账户**，标签「研究晋升」，按规格前瞻调仓，可启停；部署前预览规格与风控 |
| 4.5 | 晋升策略 × LLM | **B：平行账户 + 可选注入规格/持仓/回测摘要到 LLM 上下文**（可参考、不强制跟单） |
| 4.6 | 北极星 | **找出综合最强**（规则 / 研究晋升 / LLM / 合议都是候选臂）；**不是**「证明 AI 强还是规则强」 |
| 4.7 | 规则探索方式 | **B：规则库 + 研究层网格/批量回测；仅存活者（建议+人确认）开前瞻账户**；禁止笛卡尔积全开活账户 |
| 4.8 | 「最强」排序 | **D：主排序夏普；副显示收益/回撤/超额；夺冠须样本达标且夏普第一**；未达标灰显不授冠 |
| 4.9 | 活账户上限与退役 | **B：硬上限 + 人确认退役**；默认可竞赛 rule/晋升臂上限约 8～10（设置项）；弱臂标「建议退役」须人点 |
| 4.10 | 锚 vs 可竞赛 | **池内等权 = 锚（role=anchor）**，不占晋升名额、不被挤掉；**S2 = 可竞赛**，可退役；超额默认相对锚 |
| 4.11 | 理论来源 | **v1 = A：只翻译用户带来的理论**（NL→规格）；**B（AI 提议）/ C（主动研究 Agent）后续补充** |
| 4.12 | 废弃/退役 | **A：软归档**；状态机 draft→…→discarded/retired；原因可选；不物理删除历史 |
| 4.13 | 交付分期 | **A：先可见性与可控**（P0 数据源+流水线+取消 → P1 设置全收口+全局日志 → P2 策略/研究拆分+对照台 → P3 研究闭环 → P4+ 网格/AI 提议等） |
